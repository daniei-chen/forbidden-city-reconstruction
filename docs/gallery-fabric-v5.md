## 实际修改

四段廊庑共6,543块铺砖先焊接顶面与侧面重合顶点，再加入1.2毫米、三段的原生倒角修改器。砖缝与原地坪标高保留。四段铺砖的原始面数和完整宫城场景中的求值面数如下：

| 铺砖网格 | 原始面 | 倒角求值面 |
| :--- | ---: | ---: |
| 协和门北庑长段 | 7,867 | 89,585 |
| 协和门南庑长段 | 7,676 | 87,445 |
| 熙和门北庑长段 | 8,117 | 92,408 |
| 熙和门南庑长段 | 9,106 | 103,727 |

62个目标网格使用42份独立材质副本，保留原材质图供比较。铺砖和连续瓦作使用按连通件稳定保存的面属性，控制低对比的色泽与粗糙度变化；朱漆、石材、灰面和彩画补充微小表面响应。实际几何改动只涉及四段铺砖。

这些倒角、颗粒、材质光学参数与色差是解释性表现，并非现场扫描的磨损或实测反射数据。两轮试渲后才保存母版；[第二轮记录](../verification/gallery_fabric_v5_study_r2.json)包含相同机位和光照下的前后对照哈希。

## 检查范围与一次检查错误

首次脚本在独立“熙和门南庑”漫游场景中求值全部四段铺砖。其中另三段不属于该场景，返回原始网格，造成倒角检查失败。[首次失败报告](../verification/validation_gallery_fabric_revision_v5.json)与[场景对照诊断](../verification/gallery_fabric_v5_bevel_diagnostic.json)均保留。

复验在完整宫城场景中求值四段实际对象，未改动模型绕过检查。原对象位置、非铺砖几何、非目标材质绑定、原材质图与全部原动画均通过保存回读核对。

熙和门南庑路线长约49.64米，24fps、960帧、40秒，名义眼高1.65米。复验完成4,800条地面射线、11,520条身体净空射线、960条头部射线与959段连续相机运动检查。它只证明这条已保存路线的取样结果，不是全城路线或完整人体碰撞认证。

## 复验与渲染脚本

`source/refine_cross_axis_fabric_v5.py`保留与试渲、构建记录一致的原始源码。修正后的独立检查入口是`source/reverify_gallery_fabric_v5.py`。两者所需的历史母版和本地研究证据不包含在源码压缩包内，不能把基础构建命令视为最新整城的完整重建命令。

`source/verify_gallery_fabric_public_v5.py`比较研究母版与公开副本的实际网格指纹、变换、动画、八份逐件属性和v5材质图，再检查公开文件的路线。

`source/render_gallery_fabric_walk_v5.py`逐帧渲染实际960帧，保存绑定模型哈希的帧回执；`source/encode_gallery_fabric_walk_v5.py`只接受完整且哈希吻合的帧序列，编码后核对时长、帧率、分辨率及完整解码。保存相机动画、几张静帧或脚本存在，都不表示完整影片已经生成。

## 尚未解决

四段各11间的计间边界、贴门短接段归属，以及1米廊庑地坪和2.62米门台的真实连接关系仍需资料。现有地坪、檐口、屋脊参数含地图估值。

补充复核发现，孙大章《清代的紫禁城》（《紫禁城》2020年第10期，印刷页55）将现状每段记为13间，与两座门的馆方页面所记11间存在差异。[原文](https://img.dpm.org.cn/Uploads/File/2020/10/23/u5f9255173a228.pdf)与[差异复核记录](../verification/cross_axis_bay_count_source_conflict_20261128.json)已定位。是否涉及短接段计间边界、历史状态或资料误差，尚不能确定；文章中的历史比较示意图也不能替代现状柱网测绘图。此次未据此擅自加两间或改变开间比例。

房壳陈设、精细雕刻、隐藏构造、真实老化分布和全城各区域精细度尚不完整。廊下图像仍较暗，不能用局部表面细修声称全城照片级真实感、逐像素1:1或连续6小时精修完成。
